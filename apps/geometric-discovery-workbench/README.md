# 点 · 线 · 结构

一个用于实时讲解“从正多面体到球杆连接，再到多方向节点系统”的交互式三维几何实验台。

本项目已并入仙童数学主页，线上入口：

<https://sintanmath.github.io/apps/geometric-discovery-workbench/>

主页构建时会自动安装依赖、跑测试并输出到 `site/apps/geometric-discovery-workbench/`。

## 单独启动

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认是：

```text
http://127.0.0.1:5173/#/scene/platonic-atlas
```

生产构建：

```bash
npm test
npm run build
npm run preview
```

## 九个场景

| 地址 | 内容 |
| --- | --- |
| `#/scene/platonic-atlas` | 同时比较五种正多面体 |
| `#/scene/skeleton` | 将面、边、点逐层拆开 |
| `#/scene/duality` | 正多面体连续变换到它对偶形体 |
| `#/scene/orthogonal-node` | 三条正交轴与六个孔口 |
| `#/scene/cube-lattice` | 用六孔节点搭建立方网格 |
| `#/scene/icosa-vertex` | 正二十面体顶点的五个连接方向 |
| `#/scene/icosa-assembly` | 十二个节点和三十根杆闭合成形 |
| `#/scene/direction-node` | 12、20、30 三类方向叠加为 62 孔节点 |
| `#/scene/zometool-node` | 62 孔实体节点及其与正二十面体顶点、面心、棱中点的对应 |

## 操作

- 拖动模型：旋转
- 滚轮：缩放
- 双击画布或按 `R`：复位视角
- 左右方向键：切换前后镜头
- `F`：切换专注模式
- 顶部工具栏：复位、自动旋转、正交/透视投影、界面显隐
- 右侧图标坞：面、边、节点、孔位、辅助线与构件尺度
- 左侧形状坞：五边形、三角形、矩形三类方向
- 在 ZomeTool 节点场景中，右侧“构件尺寸”可分别连续缩放、旋转三类孔；孔径范围为 `0.05×–8×`，转角范围为 `-180°–180°`，`1:1` 恢复推荐比例
- 装配、展开与对偶滑块下方提供 `0 / ½ / 1` 快速档位
- 在对偶场景中，`0` 是原体，`½` 是扩张中的中间形，`1` 是对偶多面体
- 在五多面体总览中，直接拖动某个模型只会旋转该模型；拖动空白处则转动观察视角

## 几何约定

- “前后、左右、上下”是三条贯穿轴，对应六个孔口，不是八个孔。
- 多面体的边从显式顶点集合的最短距离自动推导。
- 正二十面体每个顶点的度数为 5；相邻三角面中的两条边夹角为 60°。
- 终场节点以小斜方截半二十面体的 60 个顶点、120 条棱和 62 个面重建实体外形；12 个五边形孔、20 个三角形孔、30 个矩形孔分别对应正二十面体的顶点、面心和棱中点方向。页面中的红、黄、蓝仅是讲解用视觉编码。
