# 内容与视频入口整合设计

## 目标

把“仙式几何”和“微分三角”两个现成网页纳入数学功法栏目；把个人介绍改为
“仙童数学 / sintanmath”的公开创作者介绍；为每个交互项目和数学功法预留独立
的 B 站视频入口。

## 方案选择

考虑过三种视频接入方式：

1. 在每个 HTML 页面里手写视频链接。直观，但内容会分散，后续维护困难。
2. 在主页维护一张全局视频表。集中，但项目和视频之间缺少数据层约束。
3. 在每个 YAML 项目条目中加入结构化 `video` 字段。

采用第三种。每个项目都声明视频状态；未提供链接时显示“视频待补充”，以后只需
在 YAML 中把状态改为 `available` 并填写 URL。构建程序负责在主页项目条目附近
渲染视频入口。

## 数据流

`data/site.yaml` 保存介绍、项目状态、页面地址和视频地址；JSON Schema 要求已发布
的视频必须有 URL；Python 构建程序生成主页和仍在制作中的占位页。已经发布的独立
网页由 `static/works/` 原样复制，不被构建程序覆盖。

## 验证

自动测试覆盖：首页栏目和创作者信息、两个静态网页存在且不被占位页覆盖、每个项目
都有视频入口、未填写的视频不会生成无效链接，以及生成页面不包含运行时 AI 调用。
