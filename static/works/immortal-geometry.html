仙式几何篇

忘旧尺 · 观新法

残卷
线段皆有长度，二线相交皆有角度。
然长度如何相加，取决于方向；
角度如何相合，也未必出于求和。

第一式·垂直求和

若三角形 \(ABC\) 在 \(B\) 点垂直，则

\[ \boxed{ AC=AB+BC } \]
长度只在垂直方向上直接相加。

第二式·同向转化

若三点共线，且相邻两段长度皆为 \(1\)，则整段长度为

\[ \boxed{ 4 } \]
同向长度不可直接相加，须借垂直关系转化。

第三式·角度

角度取值于 \(0\) 与 \(1\) 之间。

\[ 0\le A\le1 \]

平行为 \(0\)，垂直为 \(1\)。角度不辨锐钝，也不沿圆周累加。

第四式·三角定律

设三角形三边长度为 \(a,b,c\)，其相对角度为 \(A,B,C\)。

\[ \boxed{ \frac{A}{a} = \frac{B}{b} = \frac{C}{c} } \]
\[ \boxed{ (a+b-c)^2 = 4ab(1-C) } \]
\[ \boxed{ (A+B+C)^2 = 2(A^2+B^2+C^2)+4ABC } \]

残卷批注

见数不可妄加，见角不可妄求其和。
方向决定长度的合成，方程约束角度的关系。
莫以旧法解释新量，先观它能生出怎样的几何。
