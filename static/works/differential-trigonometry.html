微分三角篇

观三边之动 · 察万象之变

残卷
凡三角之形，定于三边。
三边既动，则角、面积、圆、高，皆随之而变。
人阶弟子背其形，地阶修士察其变。

总纲·三边化万象

设三角形三边为 \(a,b,c\)，其对角为 \(A,B,C\)，面积为 \(S\)，外接圆半径为 \(R\)。

三边既定，三角形的内禀几何量皆可视作三元函数。

\[ F=F(a,b,c) \]
地阶之法，不再将面积、角度与圆半径视为静止之数， 而将其视作随三边流转的几何函数。

第一式·面积感应

固定 \(b,c\)，只令对边 \(a\) 微动，则面积之变化率为：

\[ \boxed{ \frac{\partial S}{\partial a}=R\cos A } \]

循环轮转可得：

\[ \frac{\partial S}{\partial b}=R\cos B, \qquad \frac{\partial S}{\partial c}=R\cos C \]

故三边同时微动时：

\[ \boxed{ dS = R\cos A\,da + R\cos B\,db + R\cos C\,dc } \]
锐角之对边增长，则面积一阶增加； 钝角之对边增长，则面积一阶减小； 若对应角为直角，则面积对该边的一阶变化为零。

第二式·角度感应

固定 \(b,c\)，只令对边 \(a\) 微动，则角 \(A\) 的变化率为：

\[ \boxed{ \frac{\partial A}{\partial a} = \frac{a}{2S} = \frac{1}{h_a} } \]

高愈小，则角度对边长的变化愈敏感。当三角形趋近退化时，

\[ h_a\to0 \]

因而角度变化率趋于剧烈。

若改变邻边，则有：

\[ \boxed{ \frac{\partial A}{\partial b} = -\frac{\cot C}{b} } \]
其余诸式，不必逐一背诵。只须同时循环置换 \(a,b,c\) 与 \(A,B,C\)，即可自行生成。

第三式·齐次天衡

若几何量 \(F\) 满足

\[ F(\lambda a,\lambda b,\lambda c) = \lambda^kF(a,b,c), \]

则称 \(F\) 为 \(k\) 次齐次量。其偏导必受欧拉天衡约束：

\[ \boxed{ aF_a+bF_b+cF_c=kF } \]

长度为一次齐次，面积为二次齐次，角度为零次齐次。

对面积施展齐次天衡：

\[ aS_a+bS_b+cS_c=2S. \]

再代入面积感应式，便得：

\[ \boxed{ a\cos A+b\cos B+c\cos C = \frac{2S}{R} } \]

借正弦定理继续化形，又得纯角恒等式：

\[ \boxed{ \sin 2A+\sin 2B+\sin 2C = 4\sin A\sin B\sin C } \]
一条偏导法诀，经过齐次天衡，便可自行生出三角恒等式。

第四式·形变极境

若周长固定，则允许的微小形变满足：

\[ da+db+dc=0. \]

若面积抵达极值，则对一切允许形变皆有：

\[ dS=0. \]

因而面积梯度必须与周长梯度同向：

\[ S_a=S_b=S_c. \]

代入第一式：

\[ \cos A=\cos B=\cos C. \]

于是：

\[ A=B=C=\frac{\pi}{3}. \]
固定周长之下，等边三角形面积最大。 人阶以海伦公式展开苦算；地阶只观其一阶变化。

残卷批注

微分之道，不在求导本身，而在以局部变化照见全局结构：

\[ \mathrm{geometric\ quantity} \longrightarrow \mathrm{differential\ law} \longrightarrow \mathrm{identity\ or\ extremum} \]

一条短小的偏导法诀，往往可以生出：

  • 全微分；
  • 齐次恒等式；
  • 约束极值；
  • 形状不变量；
  • 特殊三角分支。
此篇尚残。卷尾隐约可见更高层次的闭合、相容与函数依赖之术。
\[ F_{ab}=F_{ba} \]
\[ \det \frac{\partial(F,G,H)} {\partial(a,b,c)} =0 \]

若三角之量皆可微，
则诸恒等式，或非背诵所得，
而是由形变自行显现……
