数字区

提示：右键点击数字卡片（或卡片右上角的 ⋯）可展开菜单进行化简 / 删除
化简规则（点开查看）

eml 运算自动做的基础化简：

  • exp(0) → 1，exp(1) → e，exp(-n) → 1/e^n（n 为正整数）
  • ln(1) → 0，ln(e) → 1，ln(0) → ln 0（保留为符号，代表 −∞）
  • exp(ln y) → y，ln(exp x) → x
  • exp(ln 0) → 0，exp(a − b) → e^a / e^b
  • ln(a / b) → ln a − ln b，ln(c^{1/n}) → ln c / n
  • a − 0 → a，a − a → 0，0 − a → −a，a − (b − c) → c（当 a == b 时）
  • 组合：(p+q) − (p−q) → 2q，(p+q) + (p−q) → 2p，a + a → 2a
  • 约分：(a·b)/b → a，(a·b)/(c·b) → a/c 等

右键菜单里的手动化简规则（不自动触发）：

  • 负指数：e^{-a} → 1/e^a
  • 欧拉公式：e^{iθ} → cos θ + i·sin θ
  • cos 偶函数：cos(−a) → cos a；sin 奇函数：sin(−a) → −sin a
  • JSON 规则：ln(−1) → π·i，√(−1) → i 等（见 simplifications.json）
  • 深度化简：一次性把上述规则反复套到收敛为止
