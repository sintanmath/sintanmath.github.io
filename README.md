# 仙童数学

我是仙童数学，英文名 sintanmath。我在 B 站做数学科普，也把视频里的实验和讲义做成可以打开、可以动手的网页。

- 主页：<https://sintanmath.github.io/>
- B 站：<https://space.bilibili.com/490068376>

## 这个仓库里有什么

这是主页的源码。线上目前主要有两类内容：

- **交互数学**：可以在浏览器里直接操作的实验。比如「点 · 线 · 结构」、Zometool 虚拟构建、eml函数、三次曲线加法。
- **数学功法**：专题讲义和课件入口。比如三角函数人阶篇、仙式几何、微分三角。

介绍文字、条目和链接都写在 [`data/site.yaml`](data/site.yaml) 里。改这份文件，主页就会跟着变。
