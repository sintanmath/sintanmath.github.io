# 仙童数学

我是仙童数学，英文名 sintanmath。我在 B 站做数学科普，也把视频里的实验和讲义做成可以打开、可以动手的网页。

- 主页：<https://sintanmath.github.io/>
- B 站：<https://space.bilibili.com/490068376>

## 目前可以体验的内容

可以在浏览器里直接玩：

- [点 · 线 · 结构](https://sintanmath.github.io/apps/geometric-discovery-workbench/)：从正多面体到球杆连接的三维几何实验台
- [Zometool 虚拟构建](https://sintanmath.github.io/apps/zometool-builder/)：用虚拟球杆搭建结构
- [eml函数](https://sintanmath.github.io/apps/eml-function/)：从一个算子构造新常数
- [三次曲线加法](https://sintanmath.github.io/apps/cuspidal-cubic-addition/)：在曲线上用弦切法演示两点相加
